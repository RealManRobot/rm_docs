## 固件升级

针对关节进行固件版本升级，升级后需重启关节才能生效。

![alt text](image-35.png)
<center>固件升级页面</center><br>

::: warning 注意
CANOpen关节暂不支持在该页面进行升级，如需升级CANOpen关节，请联系我司技术支持。
:::

1. 输入待升级的关节ID。
    ![alt text](image-36.png)<br>
    <center>关节选择</center><br>
2. 点击`选择文件`，打开存放固件文件路径，选择准确的固件文件，并点击`打开`，完成选择固件文件。<br>
    固件文件后缀为bin文件。
    ![alt text](image-37.png)<br>
    <center>文件选择</center><br>
3. 点击`开始更新`，开始固件升级更新。
    ![alt text](image-38.png)
    <center>开始更新</center><br>
4. 升级完成后，请重启关节，使关节固件版本升级生效。
