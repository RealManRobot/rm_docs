## 系统错误代码

系统错误根据严重程度分为一般和严重两个等级，其定义如下：

- 一般：机械臂使用时发生错误报警，告知用户相关异常，清除错误后机械臂可继续正常；
- 严重：指发生硬件损坏或程序崩溃等严重问题，在此状态下不应该再继续使用。

- 严重：需重新烧录固件或返厂维修。
